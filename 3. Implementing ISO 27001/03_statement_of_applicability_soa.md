# Statement of Applicability (SOA)

This document lists selected ISO/IEC 27001 Annex A controls and explains whether they apply to the organization. This is a simplified example created for learning purposes.

---

## Control Selection Summary

| Annex A Control | Control Name | Applicable? | Reason |
|-----------------|--------------|-------------|--------|
| A.5.15 | Access control | Yes | User access to email and systems must be restricted |
| A.5.17 | Authentication information | Yes | User accounts require secure login methods |
| A.5.24 | Incident management planning | Yes | Security incidents must be handled consistently |
| A.6.3 | Information security awareness | Yes | Employees are a common target for phishing |
| A.8.8 | Management of technical vulnerabilities | Yes | Systems must be kept up to date to reduce risk |

---

## Notes

Only a small number of controls are listed to demonstrate how control selection works. In a real organization, the SOA would include all applicable controls.
