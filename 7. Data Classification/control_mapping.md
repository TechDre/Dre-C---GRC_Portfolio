# Data Classification Control Mapping
Internal GRC Portfolio Project

This document maps the Data Classification Policy to common security frameworks to demonstrate how data governance supports risk management and compliance objectives.

---

## Control Mapping Overview

| Data Classification Requirement | NIST SP 800-53 Control | ISO/IEC 27001 Control | Description |
|--------------------------------|------------------------|------------------------|-------------|
| Identify and classify data based on sensitivity | PL-2, RA-2 | A.5.12, A.8.2 | Ensures data is identified and categorized to support appropriate risk treatment |
| Restrict access based on data classification | AC-3, AC-6 | A.9.1, A.9.4 | Enforces least privilege access to sensitive data |
| Protect sensitive data using encryption | SC-12, SC-13 | A.10.1 | Ensures confidentiality and integrity of classified data |
| Assign data ownership | PL-2, PM-1 | A.5.1 | Establishes accountability and governance over data |
| Secure handling of restricted data | IA-5, CM-6 | A.8.3 | Prevents unauthorized disclosure of highly sensitive information |
| Define retention and disposal requirements | MP-7 | A.8.10 | Supports compliance with legal and regulatory requirements |

---

## GRC Value Statement
By mapping data classification requirements to recognized security controls, the organization demonstrates a structured, risk-based approach to data protection that supports governance oversight, regulatory compliance, and audit readiness.
